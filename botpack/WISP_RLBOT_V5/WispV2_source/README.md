# Wisp v2

Wisp is a Rocket League bot made with [GigaLearn](https://github.com/ZealanL/GigaLearnCPP-Leak) and [RLBot](https://rlbot.org/).
Wisp plays 1s, 2s, and 3s with focus on possession, teamwork, and aerials.

Various versions of Wisp are available to play against -- but not for cheating!
Find Wisp in the [RLBot](https://rlbot.org/) bot pack or on RocketHost (best version is only on RocketHost).

You can also catch Wisp playing on the [RLGym 24/7 stream](https://www.twitch.tv/rlgym).
